# Дом культуры Муравленко

Адаптивный сайт об истории и обновлении Дома культуры. Архив, проектный замысел, ход работ, сравнение фасадов, залы, площадь и карта.

## Запуск и публикация

Для локального просмотра запустите HTTP-сервер в корне репозитория, например `python -m http.server 8000`. GitHub Actions публикует сайт после обновления ветки `main`. В настройках GitHub Pages источником должен быть **GitHub Actions**.

Сайт доступен на [GitHub Pages](https://lordpandocha.github.io/Dk/).

## Изображения

Сайт загружает отдельные WebP-файлы из `assets/photos/`. Снимки и архитектурная визуализация извлечены из презентации «Дом культуры. История обновления городского пространства». Архивные планшеты предоставили Государственный архив ЯНАО и администрация Муравленко для выставки [«Строим Ямал»](https://yamal-news.ru/society/2026/10/30/103474.html). История названий сверена с [фондом № 25 «Архивов Ямала»](https://funds.yamalarchives.ru/funds/view/1300).
